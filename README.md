## Technologies Used
Used HTML, CSS, vanilla Javascript and Firebase as Realtime Database, Cloud Storage & Web hosting. Utilised various libraries too such as Greensock animation platform (GSAP).

## Responsiveness
The site is fully responsive using pure CSS using properties such as clamps and media queries to ensure a fulfilling experience over a number of devices.
